無線の左右分割キーボードの起動方法
サブ（右側）の電源を入れて、マスター（左側）の電源を入れる
キーボード同士がペアリングされたのちにデバイスと接続されます。
逆の手順にした場合、スムーズに接続されない場合があります。

ファームウェアの転送（configに転記するかも）
ファームウェアをダウンロードして解凍すると３つのファイルが格納されています。
それぞれ以下のような役割を持っています。

転送手順（左右どちらからでもいい）
キーマップの変更の身であればマスター（左側）のみの更新、リセットも不要
・本体をパソコンとケーブルで接続
・リセットボタンを２回押す
・フォルダにリセットファイルをコピペ
・接続が解除される
・リセットボタンを２回押す
・フォルダに対象の左ならＬ、右ならＲをコピペ
・接続が解除される
